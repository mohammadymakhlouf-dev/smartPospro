# SmartPOS Pro — النسخة التجريبية الأولى

برنامج مبيعات ومخازن باللغة العربية، يعمل على المتصفح وعلى الأجهزة التي تدعم تطبيقات الويب (PWA).

## كيفية نشر الموقع

1. افتح مستودع GitHub: https://github.com/mohammadymakhlouf-dev/smartPospro
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم **main** و **/(root)**، واضغط Save.
4. بعد إكمال النشر سيكون عنوان الموقع غالبًا:
   https://mohammadymakhlouf-dev.github.io/smartPospro/
5. افتح Google Cloud Console → Google Auth Platform → Clients → OAuth Web client، وأضف هذا العنوان إلى Authorized JavaScript origins:
   https://mohammadymakhlouf-dev.github.io
   (بدون مسار المستودع).
6. في Google Auth Platform → Data Access، أضف الصلاحية:
   https://www.googleapis.com/auth/drive.appdata
   ويُستخدم معها openid/email/profile لتحديد حساب صاحب المحل.
7. إذا كانت شاشة موافقة OAuth في وضع Testing، أضف حسابات الاختبار إلى Audience → Test users.

## ما يعمل الآن

- تسجيل Google (عند توفر الإنترنت)؛ يحتفظ البرنامج بمخزن IndexedDB منفصل لكل Google account ID.
- دخول غير متصل إلى البيانات الموجودة مسبقًا على الجهاز (لا يُعيد التحقق من الهوية).
- إعداد اسم المنشأة والنشاط التجاري والعملة.
- إنشاء وتعديل وحذف المنتجات مع باركود وسعر تكلفة وبيع ومقاس ولون ومخزون.
- كاشير: البحث بالاسم أو الباركود، قارئ USB/Bluetooth الذي يعمل كلوحة مفاتيح، خصم وفاتورة.
- خصم المخزون وتسجيل الفاتورة محليًا في معاملة واحدة عبر IndexedDB.
- سجل الفواتير والطباعة والتقارير الأساسية.
- نسخ احتياطية JSON يدوية إلى الجهاز، واستعادة مع فحص أن النسخة تخص نفس حساب Google.
- نسخ احتياطي إلى Google Drive appDataFolder باستخدام حساب كل صاحب محل (زر يدوي، أو بعد دقيقة من تعديل محلي عند بقاء جلسة Google صالحة).
- أصول PWA تعمل دون اتصال بعد تحميل الصفحة بنجاح لأول مرة.

## حدود مهمة قبل استخدامه في متجر فعلي

هذه نسخة أولية غير مختبرة على جميع الأجهزة. لا تستخدمها مباشرة مع معاملات مالية حقيقية دون اختبارات كاملة.

- Google Drive هو **نسخ احتياطي واستعادة، وليس مزامنة لحظية متعددة الأجهزة**. استخدام جهازين للفاتورة نفسها قد يسبب تضاربًا أو فقدان تغييرات عند استعادة نسخ قديمة.
- النسخ السحابي الحالي يحافظ على أحدث نسخة واحدة؛ لا يوجد سجل نسخ تلقائي أو حل تعارضات، لذلك ينبغي أيضًا حفظ نسخ JSON خارجية بشكل منتظم.
- عند انتهاء صلاحية OAuth أو انقطاع الإنترنت يتوقف الرفع السحابي حتى إعادة الاتصال؛ البيانات المحلية تبقى على الجهاز.
- وضع الدخول دون إنترنت يعتمد على آخر حساب مستخدم على الجهاز **ولا يتحقق من هويته**. لا تستخدم الوضع دون إنترنت على أجهزة مشتركة قبل إضافة قفل PIN/صلاحيات مستخدمين.
- حذف بيانات المتصفح قد يمحو التخزين المحلي؛ راجع وضع التخزين وحافظ على نسخ احتياطية.
- نسخة JSON المحلية غير مشفرة.
- لا توجد بعد إدارة مفصلة للمطاعم والطاولات، أو ضرائب، أو مرتجعات، أو اشتراكات، أو مزامنة Firebase، أو إدارة مستخدمين متعددة، أو منع بيع متزامن على أجهزة متعددة.

## الملفات

- `index.html`: هيكل التطبيق.
- `styles.css`: تنسيق احترافي متجاوب.
- `app.js`: التطبيق وIndexedDB والفواتير والمخزون والتقارير.
- `drive.js`: تسجيل Google وGoogle Drive API.
- `manifest.webmanifest`, `sw.js`, `icon.svg`: أساسيات PWA.

Client ID مستخدم في `drive.js` ومُقيد بمواقع JavaScript origins المعتمدة. لا تحفظ أي OAuth Client Secret في الملفات العامة.
